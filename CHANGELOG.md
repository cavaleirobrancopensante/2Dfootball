# Changelog

Bump `config/version` in `project.godot` for each release. Every push to `main` republishes the browser build.

## 1.0 — 2026-10-19
- First playable: 5-a-side match against the computer, 3 minutes.
- Team picker with 8 kits; every player gets a random skin tone and hairstyle.
- Touch controls: joystick, shoot (hold for power) / slide tackle, pass / switch player.
- AI teams: pressing, covering, passing into space, shooting at the far corner; diving keepers with saves and parries.
- Headers, slide tackles, falls, goal celebrations, win/draw/loss record.
- Browser version on GitHub Pages.
