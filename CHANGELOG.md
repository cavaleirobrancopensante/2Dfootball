# Changelog

Bump `config/version` in `project.godot` for each release. Every push to `main` republishes the browser build.

## 1.1 — 2026-10-19
- **Career mode:** four divisions with promotion and relegation, a 40-club cup, multi-season careers, finances, transfers, youth intake, retirements. Play or simulate each match. Autosaves.
- **Player ratings** (13 attributes, 1–100) drive the matches: speed, stamina, passing/shooting/crossing accuracy, shot power, dribbling, tackling, heading, keeping.
- **Age:** development and decline every summer; recovery between matches depends on age.
- **Four buttons** (PlayStation layout): pass (hold for a long ball), shoot and cross with power bars, tackle / dribble (sprint and skill moves).
- Headers from crosses, heavy first touches, keepers spill hard shots.
- Pause menu; goal scorers shown.
- 6 more hairstyles (12 + bald).
- Editable fictional database in `data/database.json`.

## 1.0 — 2026-10-19
- First playable: 5-a-side match against the computer, 3 minutes.
- Team picker with 8 kits; every player gets a random skin tone and hairstyle.
- Touch controls: joystick, shoot (hold for power) / slide tackle, pass / switch player.
- AI teams: pressing, covering, passing into space, shooting at the far corner; diving keepers with saves and parries.
- Headers, slide tackles, falls, goal celebrations, win/draw/loss record.
- Browser version on GitHub Pages.
